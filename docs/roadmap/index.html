Roadmap

One card = one PR. Everything builds on the plan format from PR 0, so PR 0 has to work first.

Goal framing (decided): no "$0 by a date" target. The agent gives the best next steps for your situation (highest net worth in 24 months), shown next to the bare minimum (minimums only, interest paid). You decide; the agent says when your idea is worse and why.

Order and dependencies

Orange = gate · blue = next (parallel after 0) · purple = after that.

Added after PR 0 landed: PR 8 (unknown transfers) and PR 9 (demo replay) are high priority and can start now. PR 10 (plan over time) and PR 11 (faster runs) also depend only on PR 0.

PR 8 Fix the "unknown transfers" high prioritydecision needed

C001 sends ~$2,890/mo from checking to "an unlisted external account". PNC's README says these are artificial calibration flows the data generator added so balances hit the final snapshot, not real behavior. The plan leans on them: it redirects ~$2,650/mo, and without that, the high-cost debt never hits $0 within 24 months (net worth $30,986 vs $29,111 baseline).

Options: (a) explain the flow with our linked-accounts layer: split it into labeled synthetic flows (linked debt minimums, other-bank card spending, rent or bills paid elsewhere, a real leftover), so the agent cuts named things. (b) Treat it as unknown: plan without it and have the agent ask "where does $2.9k/mo go?"

PR 10 Plan over time: the home page, before vs after

The outcome screen mirrors the home page, but over time, so the user sees what changed:

  • Before vs after, per account: what you pay each debt now vs under the plan, plus savings, investing and the redirect.
  • Each account over time: the balance of every debt and asset by month, with a month scrubber.
  • Income and expenses: income now (and estimated ahead) and spending by bucket, before vs after.
  • Every change, and every non-change: "PNC card: $236 → $1,900/mo", "Federal loan: keep paying the $195 minimum", "Groceries: no change".

PR 3 Reality check: when rearranging isn't enough

Code checks whether debt can shrink with the current income and spending at all. If not, the plan leads with the gap: "You're $X/mo short. Spend $X less or earn $X more." The agent then picks which changes are most realistic.

PR 4 Talk to the plan

After a plan exists, type or speak a change: "don't touch savings", "I can cut dining more". It's the same flow as planning, but it starts from the current plan plus your request. The agent can push back if the change is worse, and shows the cost.

PR 5 Checkpoints and drift check

Each approved plan saves where every debt should be each month. A plain code check (no AI) compares actuals monthly. If a debt is off by more than 1 month of payments, or spending is >15% over target, you get an alert and a re-plan through PR 4's adjust flow.
